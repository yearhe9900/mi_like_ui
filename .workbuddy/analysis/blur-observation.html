顶部 & 底部毛玻璃效果观察

依据两段录屏抽帧（暗色 5cf0c928…mp4 / 亮色 16fbd9f4…mp4，均为 1220×2656）逐帧比对，含静止与内容滚入两种状态。

一、顶部：整块悬浮毛玻璃（状态栏 + 搜索框 + 胶囊 tab 共用一层）

关键点：模糊不是单独加在搜索框上，而是整个头部区域一块 backdrop blur，从屏幕顶边盖到胶囊 tab 下方；banner 向上滚入时才显现，底部羽化渐隐（约 60–150px 过渡带），没有硬切割线。

二、搜索框（stadium 胶囊）

全圆角胶囊，宽约屏幕 92%（左右边距约 3%），高约屏高 4.5%。在毛玻璃层上再叠一层半透明填充 + 1px 细描边 + 极轻投影。
· 暗色：黑约 40–50% 填充，背后内容几乎看不清，只在底边透出一点颜色；描边是极淡的白 8–12%。
· 亮色：白约 25–35% 填充，比周围毛玻璃更「奶」一点；描边白 30–40%。
放大镜图标与占位文字均为弱化灰，占位文字约 55% 不透明度。

三、胶囊 tab（推荐 / 背屏 / 小部件 / 主题）

可横滑，右侧永远露出半个下一枚。三种状态：
· 选中：实心反色胶囊（暗色 = 米白 #EDEBE6 + 黑字；亮色 = 深灰近黑 + 白字），带极轻投影，完全不透。
· 未选中：半透明 + 各自再叠一层毛玻璃（模糊后的背景色透进胶囊里，暗色下呈灰褐、亮色下呈奶白）+ 1px 细描边。
· 静止（背后无内容）：暗色下未选中胶囊几乎与纯黑背景融为一体，只剩一圈很淡的描边；内容滚入后才「浮现」。

四、底部导航：悬浮透明毛玻璃胶囊条

一条独立的 stadium 胶囊：左右留白约 6%，距屏底约 3%（浮在手势条上方），高约屏高 6%。半透明填充 + 中等强度模糊（比顶部弱——背后图片仍可辨轮廓）+ 1px 细描边 + 柔和外投影。选中项（首页）底下有一块圆角高亮块。

八、实机反馈三轮：底栏定标复归 + 丢帧修复（2026-10-27）

结论修复
底栏玻璃定标「纯净条」（图标/高亮之外）合成匹配：σ 谷值 26px 跨帧组复现（26…30px，亮暗一致）、t≈0.25…0.30；合成对照面板（σ26/t0.285）与真实像素几乎不可分辨。含图标的窗口会把 UI 像素当内容 → 15…21px 是过拟合blurSigma 5.5→9.0dp（≈28px，真值一直如此）；深遮罩 0.48→0.70（t≈0.30）
快速滑动丢帧连续 σScale 让 MiFilterCache（以 σ 为键）每帧新建 native filter（12 层 × 每帧）= 丢帧主因；12 趟全宽高斯亦偏重σScale 0.05 档量化（同档命中缓存、换档才重建）；快速运动（scale≤0.8）9 段合并 3 段（段高加权 σ）+ 剔除 σ<1dp 段，停下恢复

方法论教训（二连）：① 拟合窗口必须避开 UI 叠加像素（图标/文字/高亮都是画在玻璃之上的硬边， 会伪装成"清晰内容"）；② 无结构化内容的窗口残差再低也不能定 σ —— σ 与透射比 t 强耦合， 必须靠多帧组交叉复现来判可信度。

十、实机反馈五轮：亮边冻结（2026-10-27）

现象：正常速度下滑亮边正常渐暗；极快下滑亮边不暗；轻碰一下内容区才变暗。 根因：σScale 量化到 0.05 档后只在换档时通知重建 —— 快滑时 σ 饱和在 0.6 档不再换档， 亮边进度（滚动位置派生）随之冻结。修正：σ 值继续量化（filter 缓存命中不变）， 通知改回逐滚动事件；每帧新建 native filter 才是丢帧主因，与重建次数无关。
