## 顶栏第 3 轮：材质改为「渐进磨砂」（推翻上一版「纯色遮罩」结论）

**用户诉求**（附录屏 `Screenrecorder-2026-10-17-12-25-51-790.mp4`，1220×2656 / 24.26fps /
6.64s）：`我发现顶部导航栏不内嵌任何组件，目前项目中顶部导航栏模糊效果和这个不一致，
请复刻视频中的效果`。

### 结论：上一版「顶栏无 backdrop 模糊」是**误判**

上一版的证据有两条，都站不住：

1. 「沿蓝卡填充色纵向取样得亮度斜坡 0.01…1.00（64.4→128.9dp）」—— 平坦色块在模糊下
   亮度**不变**，该斜坡只能来自叠色；但取样列落在卡片**顶缘之外**时同样会读出斜坡，
   无法区分；
2. 「卡片下缘 113 → 0 在 3px 内完成（无拖尾）」—— 该卡片顶缘在 183dp，本来就在
   模糊带（≤119dp）**之下**，当然锐利。

换成**高频内容**（头像照片的圆边、圆角方块的竖直边）后，模糊是确定性存在的。

### 实测（亮色「我的」页，s = 393/1220 = 0.32213 dp/px）

有效 σ（dp），两条独立方法交叉验证（边缘 10-90 宽度 / 同行频谱比）：

| y (dp) | 0…35 | 50 | 67.5 | 90 | 103 | 109 | ≥119 |
|---|---|---|---|---|---|---|---|
| σ | 5.37 | 4.96 | 4.34 | 1.85 | 0.76 | 0.27 | 0 |

`blurSigma = 5.37`（平台段 42.7px / 2.563 × 0.32213）。

叠色（**关键判据**，两处平坦区交叉验证）：
* 同帧页底 #F3F3F3(243) 在栏内**全程不变** → 排除白色叠色；
* 白卡填充 255 在栏内 80dp 读 **249**，同帧栏外读 255 → 排除"无叠色"，
  249 = 255 − (255−243)×0.50，即 **叠色 = 页底色 @α**；
* α(y) 由 1-D 逐行反卷积 + PAVA 单调平滑：0.650(顶) → 0.594(57) → 0.501(88) →
  0.314(103) → 0.055(118.5) → **0(122.4dp)**。

遮罩 m(y) 由边缘宽度反解（模型 `观察值 = (1−m)·原内容 + m·模糊(原内容)`）：
1.00(0…35) → 0.98(34.6) → 0.85(50.1) → 0.67(67.5) → 0.30(90) → 0.24(102.9) →
0.14(108.7) → **0(119)**。

### 实现

* `ShaderMask(blendMode: dstIn, shaderCallback: blurMask)` 包 `BackdropFilter`
  （`ClipRect` 在外）→ 遮罩为 1 处只留模糊、为 0 处只留原内容，正好是上式。
  **不能用半透明色层模拟**（只压暗、不抹细节），也不宜用多层 `ClipRect` 分段
  （分段边界在模糊场上留接缝）。
* `MiTopBarPalette` 新增 `blurSigma` / `blurMask`（明暗通用）；浅色 `scrimGradient`
  换成实测 α(y)（12 stop）；深色配方不动。
* `MiTopBar.title` 改可空 → **纯材质形态**（不内嵌任何组件，高度收到 `scrimHeight`），
  与录屏同构；`showBack` 仍可单独用。
