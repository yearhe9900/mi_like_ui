## 新增 MiMenu 锚定菜单（7913608 + 455949b + 3bf6462 + 1067fd2，已 push）

- 参照物：`flutter_miuix` 的「Menus」不是单个组件而是 `Miuix*DropdownPreference` / `MiuixListPopup` / 级联弹层的陈列页。本库没照搬 preference 层（设置行已存在），只抽出一个 `MiMenu`：**只量 child 盒子做锚点、不接管点按**，靠 `MiMenuController` 开合 —— 这样 `MiSettingsRow` 自己就是入口。
- 落位：`lib/src/overlays/menu/`（`menu.dart` / `menu_metrics.dart` / `menu_painter.dart`）。放浮层的原因不是「弹层」而是分层：`overlays` 不许 import `components`，菜单要包任意 widget 做锚点，进 components 会逼它反向依赖。
- 定位是纯函数（`MiMenuMetrics.panelOffset` 右缘对齐 → 下方优先 → 翻上方 → 夹紧宿主；`revealFromBottom` 决定缩放原点），可单测，不依赖 RenderBox。
- 两个坑：①面板经 `MiPopup` 渲染到宿主，**宿主在页面 Scaffold 之外**，缺 `Material`/`DefaultTextStyle` → 文字变方框 + 黄下划线（给面板补 `MaterialType.transparency`）；②弹簧落定在 0.9999 而非 1，缩放层让面板窄 0.1% → 宽度断言放宽到 ±0.5dp（别收紧回 0.01）。
- 级联二级「返回行」的箭头要**水平镜像**（`MiMenuChevronPainter(back: true)`），照抄参考会朝右、看着像进入下一级。
- 预览图必须把 `MiPopupHost` 放进**截图子树内**（`KeyedSubtree` 里），否则只截到被压暗的页面、面板在 golden 之外。
- 验证：`flutter analyze` 新增文件零告警（lib 16 条 / test 88 条均为既有）；`flutter test` 415 全过（menu 9 例 + 展示页 2 例 + 预览 2 例）。提交拆 4 个语义提交后 push，`main...origin/main` 同步。
