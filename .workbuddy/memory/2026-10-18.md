## 把「顶部渐进模糊」抽成独立组件 MiGradientBlur

用户先问「现在顶部模式，是不是已经和顶部导航栏没关系了」，我回答：**语义上解耦、
物理上还没**（模糊只在 `MiTopBar.build` 里画，不用顶栏的页面拿不到）。用户回「拆分」。

**新文件**
* `lib/src/theme/gradient_blur_tokens.dart`：`MiTopBarBlurBand`（类挪过来，名字不变）
  + `MiGradientBlurProfile`（`sigma` 5.37 / `nominalExtent` 119 / `minVisibleSigma`
  0.5 / `bands` 8 段）。`top_bar_tokens.dart` 里 `export ... show MiTopBarBlurBand,
  MiGradientBlurProfile`，`MiTopBarPalette.blurSigma/blurBands` 与
  `MiTopBarMetrics.minVisibleBlurSigma` 改成**转发**（旧引用零改动）。
* `lib/src/components/effects/gradient_blur/gradient_blur.dart`：`MiGradientBlur`
  - `height`（作用区，曲线等比拉伸到此归零）、`opaqueScrimBottom`（**最终 dp**，
    压色盒拉伸后的下沿）、`underSurface`（上层是否真有那层不透明压色）
  - `static bandsFor({extent, opaqueScrimBottom, underSurface})` 纯函数；`extent<=0` 返回空
    （踩过：`extent>0 ? : 1.0` 会把 0 当 1 返回整条曲线）

**顶栏侧**：`build` 的材质层里把「for band → Positioned(ClipRect+BackdropFilter)」
换成 `if (showBlur) MiGradientBlur(height: materialHeight, opaqueScrimBottom: …*k, underSurface: showSurface)`；
`MiTopBar.visibleBlurBands` 保留为 `@visibleForTesting` 转发（既有测试不改）。

**验证**：`flutter test` **136 项全绿、一张 golden 都没变**（零视觉差异 ✓）；
`dart analyze` 0 error/0 warning。新增 `test/gradient_blur_test.dart` 9 条。

**注意**：`BackdropFilter.filter` 在本 SDK 是可空类型（测试里返回类型要写 `ImageFilter?`）。

## 侧栏两连改：内外圈等距 + 绿色圆钮

**① 内外圈间距（用户反馈：平板模式内外圈间距应一致，以内圈为准）**
- 根因：`SideNavPainter` 栏体圆角自算 `size.width / 2`（47.7 stadium），与内圈
  胶囊（圆角 24.65、顶角圆心 y=31.25）**不同心**——两圆弧相交，胶囊肩部与栏体
  轮廓间距从 6.6 收缩到 0（顶角甚至穿出被 ClipRRect 裁掉）。
- 修法：`railRadius = pillRadius + railInnerPad`（31.25）＝以内圈为准等距外扩，
  端头圆弧同心、间距四周恒 6.6（底部栏「同心 + 恒 pillInsetV」同款原则）。
- **坑**：只改 metrics 不生效——painter 若自算半径就绕过了 token；ClipRRect 半径
  变小（31.25 < 绘制 47.7）也裁不到任何像素，预览图逐字节不变、测试照过。
  用像素 diff（ImageChops bbox）定位到唯一差异区只有圆钮位置才发现。改几何
  token 必须连 painter 一起核对。

**② 绿色圆钮（MiGlassNavFab）进侧栏**
- `MiGlassSideNavBar.fab`：挂在**栏尾下方**、水平居中（直径 55.4 / 间距 11.9
  沿用底部栏实测）；栏体不让位（侧栏锚定左上，无居中腾挪语义）。槽位恒定预留
  （`heightFor(n, hasFab)`），显隐只有 Opacity/Scale 动画、零布局跳动。断言同底
  部栏：≤3 条目、tabIndex 范围。
- demo：手机/侧栏**共用同一份 fab 声明**（tabIndex 0 首页、点按弹 SnackBar）。
- **坑**：`IgnorePointer` 必须包在 `GestureDetector` **外面**——后者自身 opaque，
  包在里层时圆钮收起（opacity 0）该区域仍命中、吞点击；底部栏同款隐患一并修。
  回归：桌面/底部栏各一条「收起不吃点击」（tapAt 圆钮位不触发回调）。
- 测试 +8（desktop_nav_test 圆钮组 4 例 + 等距 metrics 例；fab_golden_test 1 例
  吃点击回归；demo 级显隐/点按/绿色断言）；6 张含侧栏预览图重生成。
  全量 146 例绿、analyze 0 error。

## 平板/桌面铺满窗口 + 状态栏透明（实拍反馈）

- 反馈（平板截图 1536×2560 @2x → 768×1280）：① 「应该铺满屏幕，不需要外围卡片效果」；② 「状态栏为什么呈现灰色」。
- `DemoStage`：medium/expanded 画面 = 窗口（删 24 留白 / 圆角 56 / 投影 / 上限 1000；`wideMaxWidth`·`minStageHeight`·`gutter` 删除）；只有 compact 仍是 393×856 物理手机画布。非 compact 的 `scale` 恒 1、零变换层。
- 灰带成因（像素实测）：状态栏区 250 → 183 的系统压色 + 应用窗口从状态栏下方开始 → 那一条既不是页面底色也不是顶栏材质。修法：`main.dart` 开 `SystemUiMode.edgeToEdge`；`DemoHome` 外层 `AnnotatedRegion<SystemUiOverlayStyle>`（透明状态栏/手势条 + 图标亮度随明暗翻转）。
- 安全区：侧栏顶 = `padding.top + 25.5`，底栏底 = `24.2 + padding.bottom`，Home 指示条同款；顶栏本来读 `MediaQuery.padding.top`。
- 坑：`Container.clipBehavior` 在 `Clip.antiAlias ↔ Clip.none` 之间切会让内部增删裁剪层 → `MockPage` 的 Element 重建、跨断点滚动位置归零。改为恒定 `Clip.antiAlias` + `BorderRadius.zero` + 空 `boxShadow`（像素零差）。
- 预算重测（铺满后宽度变大）：768 首页 7/78,562、我的 6/52,142、分类 8/109,360；1366 首页 7/137,506、分类 8/194,809。
- 测试：`desktop_nav_test` 新增「铺满（圆角 0/无投影）」「状态栏透明 + 图标亮度」「侧栏让开状态栏/底栏让开手势条」；断点用例改 600 底栏 / 601 侧栏；`responsive_test` 外壳尺寸期望改为窗口尺寸。预览图 adaptive_tablet/desktop/light 全部重生成（无卡片）。
