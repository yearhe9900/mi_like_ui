- `MiDimens.disabledOpacity`(0.38) 上提为全库禁用档（switch_metrics 同源转发）；

## Switch 补齐（commit 11fd1ea / 994f3d4）

用户「Switch 按钮也加上」——本库早有 `MiSwitch`（但 demo 一直用 Material `Switch`，
从未陈列自己的），所以这轮 = **补交互 + 换 demo**。

### 补齐的三个交互（对齐 flutter_miuix `MiuixSwitch`）
- **水平拖拽切换**：`_ctrl.value += delta / travel`（直接跟手）；松手 `>= dragSwitchThreshold`(0.5)
  即 `onChanged(!value)`；归位 `addPostFrameCallback` 里按**最新** `widget.value` 决定
  （宿主同帧接受→弹新端，拒绝→弹回原端），比上游「直接 `_animateThumbPos(widget.value)`」更稳。
- **钮体按压放大 1.127**（上游参考值），过渡**复用** `MiMotionTokens.pressMs/pressCurve`
  （不另造时长）；用 `TweenAnimationBuilder` 跟随 `_active`。
- **RTL 镜像**：`right: left` 定位 + 拖拽 delta 取反。

### 关键手法：按下态怎么拿
`MiPressable.pressBuilder` 只能拿到 `pressed` 且只能包整体子树 → 给不了「只放大钮体」。
解法：外层 `Listener(onPointerDown/Up/Cancel)` 自己跟踪 —— **Listener 不参与手势竞技场**，
不会抢 `MiPressable` 的 tap；拖拽用内层 `GestureDetector(onHorizontalDrag*)`（更深→优先，
tap 会被自动 cancel，不会双触发）。

### 坑
- demo 里有 `find.byType(Switch)`（Material）的测试断言 3 个文件 6 处：`desktop_nav_test`、
  `light_mode_golden_test`、`preview_capture_test` —— 换组件后**必须同步改**，否则
  「Found 0 widgets with type Switch」。
- 新增陈列后 `find.text('禁用态')` 撞车（开关/复选框各一行）→ demo 标签改
  `禁用态（开关）`/`禁用态（复选框）`；`已开启` 与 WLAN 行 value 撞车 → 热点行改
  `已连接/未连接`。**测试按文本定位时，demo 文案要保证唯一**。
- `scrollUntilVisible` 的 finder 必须唯一，否则 `Bad state: Too many elements`。

### 黄金图
demo 换皮必然改图：`test/goldens/demo_light_mine.png` + `doc/preview/{demo_light,demo_dark,adaptive_desktop_light}.png`。

## 结构重构 + 文档（commit 366a5bd / 7a82598 / af401c0 / 7360f6c + docs）

用户要求「通读项目 → 指出结构重复/职责混乱/分层不合理 → 重构且不改功能 → 补齐文档 → 输出清单」。

### 审计出的四类问题
1. **同族分三处**：`components/feedback/`（dialog、pull_up_panel、snackbar）+ `components/overlays/`
   （bottom_sheet、floating_toolbar）+ `src/overlay/`（单数，只放 popup_host）。
2. **`utils/` 混装三类**：无状态基元（squircle、glass_rim）、有状态交互（pressable、hover_feedback、
   focus_ring）、布局基建（responsive、scroll_binder），外加内部滤镜缓存（filter_cache）、cell_grid。
3. **逆向依赖**：`MiPreferenceTileMetrics` → `MiDialogListMetrics.rowHeight`、
   `preference_tile.dart` → `MiDialogMetrics.pressDurationMs`（组件层向浮层要几何/动效）。
4. **命名不一致**：`side_nav_bar.dart` 里是 `MiGlassSideNavBar`；`search_cancel_metrics.dart` 缺 `button`。

### 处理手法
- **浮层统一到 `src/overlays/`**（`git mv` 三处合并，`overlays/popup_host.dart` 替 `src/overlay/mi_popup_host.dart`）。
- **`utils/` 一拆为二**：`foundations/`（squircle / glass_rim / pressable / hover_feedback / focus_ring /
  filter_cache / cell_grid）+ `layout/`（responsive / scroll_binder）。`src/utils/` 整目录消失。
- **消除逆向依赖**：行几何上提 `theme/row_tokens.dart` 的 `MiRowMetrics`（geometry + `heightFor`），
  dialog 侧改**同源转发** → dialog 两个调用点、`dialog_list_test` / `preference_tile_test` 断言零改动。
- **文件名对齐类名**；**主题解析统一 `MiTheme.modeOf`**（slider / switch / snackbar / preference_tile 四处手写比较消除）。
- **demo 巨石 2919 行 → 194 行主文件 + 4 个 part**（profile / home / showcase / search）。
  用 `part` 而非独立文件：同一 library 里 `_` 私有名跨文件可见 → `demo_app` 与测试引用零改动。
- **新增 `test/architecture_test.dart`（8 例）** 把结论钉死：6 条依赖方向 + barrel 死链 + barrel 覆盖（排 `*_painter.dart`）。
