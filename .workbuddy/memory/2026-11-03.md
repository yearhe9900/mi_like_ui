## 对齐 flutter_miuix：Overlays + CheckBox 落地（commit dfd48a4 / dc5050b）

从 `D:\Workspace\opensource\flutter_miuix` 的 Overlays / CheckBox 里挑了**三件**能接上本库的：
`MiCheckbox`、`MiBottomSheet`、`MiFloatingToolbar`。
（ListPopup / Dropdown 属 Menus 类且量级过大，未做；MiDialog / MiPullUpPanel / MiSnackbar 已存在，不重复。）

### 落地口径（复用而非新增）
- **配色零新增**：checkbox 选中 = `MiColors.accent`、勾号墨 = `MiDialogPalette.*.filledActionLabel`；
  sheet 表面 = `MiPullUpPanelPalette.*.surface`、标题 = `MiDialogPalette.*.title`；
  toolbar 表面 = `MiSettingsPalette.cardFor(mode)`、描边 = `dialogDividerFor(mode)`、投影 = `panelShadow`。
- **几何/动效全进 `*_metrics.dart`**，注释标「参考实现值、本库无素材」（本库没有对应素材可量）；
  checkbox ⌀26 / 勾号三点 `(5,9.4)(10.3,14.9)(17.9,5.1)` / trim 0.186…0.803；
  sheet `miSpring(0.9, 0.38)`≈273ms、`dismissDistance` 150、`flingVelocity` 800、`dragResistance` 0.1；
  toolbar `cornerRadius` 50、外留白 12/8、投影 blur 10 无偏移、描边 0.75。
- checkbox 勾号用 `PathMetric` trim 逐段描（半选 = 三点向中心收拢成横杠），三段控制器并行
  （`alphaMs` 150 / `trimMs` 300 / `indetMs` 200，`Curves.fastOutSlowIn`）。

### 顺手修掉的真实缺陷
- **`MiPopupRegistry` 构建期同步 `notifyListeners()`** → 首帧即挂浮层的页面在宿主上触发
  `setState() called during build`（以前没组件这么用，所以没暴露）。改为 `_notify()`：
  非 `persistentCallbacks` 阶段直接通知，构建期合帧推到帧末（`hasListeners` 守卫）。
  **坑记**：测试里浮层几何要 pump 两帧才生效（通知推到帧末）。
- `MiSquircle` 加 `topOnly`（只圆上两角，贴底形态）与 `MiSquircleBorder.side` 描边。
- `MiDimens.disabledOpacity`(0.38) 上提为全库禁用档（switch_metrics 同源转发）；
  `controlOffFillFor` 上提为「关闭档」通用墨量（开关轨道 + 复选框共用）。

### 测试坑
- 手势 slop：`startGesture` 后单次 `moveBy(-100)` 实际位移只有约 −2.5 → 分 4 步 `moveBy(-25)`，
  每步 pump ×2。
- `tester.getSemantics(...).flagsCollection.isChecked` 直接读即可，**别 `ensureSemantics()`**
  （会报 `SemanticsHandle was active at the end of the test`）。
- `GestureDetector` 子级是空 `SizedBox` 不参与命中 → 加 `behavior: HitTestBehavior.opaque`。
- `find.byType(X).at(n)` 在 `CachingIterable` 上会 RangeError → 改按标签 ancestor/descendant 定位。
