## 顶栏第 2 轮修正：内容顶缘分档 + strut 钉基线 + 返回圆钮参数化

用户贴「设置」首页实机截图（1220×2656），要求：①**顶栏高度要对齐** ②**左箭头改为参数传入是否可显示，默认不显示**。测量脚本 `.workbuddy/measure_top_bar_settings_page.py`。

- **「高度」= 内容顶缘档位差（不是栏高）**。重测录屏静止帧确认**卡片类首行顶缘 183.0dp 是对的**（列剖面 x=400 在 183.61dp 才有 0→135 硬跳变；先前用 `(B−R)>15` 判据测到的 177.17dp 是**右卡描边**，判据会被描边骗）；而参考截图「设置」首页的**搜索栏顶缘 = 523px = 168.5dp**（同页卡片组 698px = 224.85dp，组间距 12.24）—— 比卡片档高 14.5dp。两值都是整机实测 → 不归一，新增 `MiTopBarMetrics.searchBarTopInset = 168.5` 与 `contentTopInset = 183.0` 分档；demo 首页首行是 `MiSearchBar`，`case 0` 的 padding 顶改用 `searchBarTopInset`。
- **大标题低 6.9dp 的机制（实机实测差值的根因）**：墨心在基线上方 `k ≈ 0.355em` 在 simhei / msyh / simsun 三字体 + 2 字 / 5 字样本下都很稳（0.350~0.360），但**基线在行盒内的位置 = 字体 `ascent/(ascent+descent)`**，字体间可差 0.14em —— 参考录屏 MiSans 反解 ≈0.807，Android CJK 回退字体 ≈0.95，`0.14em × 31.83 ≈ 4.5dp` 即主因（余下为墨高/抗锯齿）。原先用的「行盒中心 = 墨心 + 0.126em」是**按 MiSans 反解的修正**，换字体即失效。
- **第一次修法走错路（编译失败）**：先试「显式 strut 钉死行盒内的基线」——`StrutStyle(fontSize, height: 1.0, ascent: 0.825, descent: 0.175, forceStrutHeight: true)`。**本 SDK（`C:\src\flutter` @3.47.5）的 `StrutStyle` 根本没有 `ascent`/`descent` 参数**（`packages/flutter/lib/src/painting/strut_style.dart` 构造器只有 fontFamily/size/height/leadingDistribution/leading/weight/style/forceStrutHeight），用户 `flutter build` 报 `No named parameter with the name 'ascent'`。教训：**strut 的行盒内基线位置只能由字体度量决定**，`height` 只是按比例缩放 ascent/descent（改不了二者之比），所以「用 strut 钉基线」在这套 SDK 上不可行。
- **正确修法：用 `Baseline` 组件在布局期钉基线**。目标值 = **墨心 + 0.355em**（`MiTopBarMetrics.titleBaselineY(inkCenterY, fontSize)` → 大标题 144.20、紧凑标题 82.29）；`Baseline(baselineType: TextBaseline.alphabetic)` 会把子级基线放到「距它自己 box 顶端 N 处」，与字体 ascent/descent 完全无关，只依赖「墨心在基线上方 0.355em」这一条跨字体很稳的假设。
  - 由此彻底删掉行盒中心反推（`titleStrutAscent/Descent`、`titleInkCenterFromBoxTop`、`largeTitleBoxCenterY`、`compactTitleBoxCenterY` 全删），组件高度改为定值 `componentHeight(fontSize) = 墨心 + 一整行`（164.73，不随字体变）。
  - 布局要点（源码核对过）：`Positioned(left:…, top: 0)` → 子级拿 `BoxConstraints()`（宽高都无界）时 `RenderBaseline` 直接 `size = Size(子宽, top + 子高)`、无 clamp；紧凑标题的 `Padding → Center → Baseline` 里 **`Center` 在无界高下 shrink-wrap 且 dy 偏移恰为 0**（`maxHeight == ∞ → shrinkWrapHeight`，`alongOffset` 的 `other.dy = 0`），所以水平居中不破坏垂直落点。
- **API：`showBack` 默认 false**（顶层页无返回，正是「设置」首页的形态）。`showBack: true` 才 `Positioned` 出圆钮；其**可点性由 `onBack` 决定**（null = 只显示、不包 GestureDetector、无按压反馈）；`showBack` 同时决定紧凑标题的**对称内缩**（`backInset + backDiameter`，让开圆钮；false 时内缩 0、居中标题用满整屏宽）。demo：首页 = 顶层页形态（不传 showBack，首行搜索栏 168.5）、「我的」= 次级页形态（`showBack: true`，首行卡片 183），两种形态各演示一次。
- **测试**（`test/top_bar_test.dart`）：`harness` 显式加 `showBack`（默认 true —— 本文件大部分用例针对圆钮）；新增 group「返回圆钮显示开关（showBack）」4 例：默认值、false 时无箭头无命中区且该处点击穿透到下层、true + onBack null 只显示不可点、`showBack` 决定紧凑标题 padding（`_compactPadding` 用最近 `Padding` 祖先读取）。**几何断言改用基线**：`_baselineOf(tester, finder) = renderObject.getDistanceToBaseline(alphabetic)`，断言 `rect.top + 基线距 == 目标基线`（唯一与字体无关的可断言量）+ 墨心→基线换算值的钉值（144.20 / 82.29）。
