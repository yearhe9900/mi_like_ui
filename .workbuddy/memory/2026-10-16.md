## MiSearchBar 搜索栏（与底部导航栏共用透明磨砂参数）

- **来源**：用户提供小米主题商店亮/暗两张 881×1920 完整分类页截图（剪贴板 97900053 / fc8225e0），s=393/881=0.44608；测量脚本 `.workbuddy/measure_search_bar.py`~`7.py`（分析用，已按约定 `git rm --cached` 移出跟踪并入 `.gitignore`）。
- **「共用透明参数」判决**（关键决策）：backdrop 磨砂取 `MiTransparencyTokens.blurSigma`(28) 与 `MiGlassNavBar` 严格同源（导航栏真正共有的透明参数就是 sigma；导航栏本身不用 fillAlpha\*）。填充 alpha 走**搜索栏实测专档**：Round 5 双图平底合成反推 `out=bg·(255−α)/255+fg·α/255` → 亮 黑@**13** 平底 `#E7E7E7`、暗 白@**36** 平底 `#242424`；不套 `fillAlphaSubtle(15)`（合成 `#E5`/`#0F`，暗色偏 21 级）。专档入 `MiSearchBarPalette`（`theme/search_bar_tokens.dart`），doc 写明推导与不套 subtle 原因 —— 1:1 实测优先于字面复用。
- **几何实测**（双图交叉一致，`inputs/search_bar/search_bar_metrics.dart`）：栏高 **44.1**（99px≈44.2，与 1220 图 137px 互证+吸顶测试钉值 `56+44.1+16`）、contentInset **15.4**（图标距栏左 34.5px）、icon **17.8** 见方、图文 gap **12.0**、笔画 4px≈**1.8**、镜片圆心 6.9 / r6.0、stadium；文字 CJK 字面 advance 37px → `MiTypography.searchHint` **16.5dp w400**（原 demo 私有 `_SearchBar` fontSize 12 已修正）。

- **测量坑**：亮色取 `lum_min` 极值、暗色取 `lum_max` 极值，阈值 `thr=(fill+ext)/2`（50% 覆盖）；方向反了会把整栏判成墨迹（Round 6 教训）。

## MiTopBar 大标题折叠顶部导航栏（录屏逐帧实测）

- **来源**：用户录屏 `Screenrecorder-2026-10-16-16-07-59-796.mp4`（1220×2656@24.32fps，HyperOS 设置「显示与亮度」页，暗色），要求 1:1 复刻顶部导航栏。采样密度 3.104 px/dp（s=393/1220）。ffmpeg 用 imageio-ffmpeg 自带 v7.1（本机无系统 ffmpeg）。
- **测量方法**：rawvideo 逐帧解码 + 1-D 相位相关估计帧间滚动量 + 亮度剖面/覆盖率反解几何；脚本按约定归档 `.workbuddy/measure_top_bar_*.py`（17 个，分析用非交付物），抽帧进 `.workbuddy/video_frames/top_bar/`（已补 `.gitignore`）。原 `.tmp_frames/` 已清空删除。
- **动效结论（关键）**：
  1. 大标题**属于滚动内容** —— 质心位移与滚动位移逐帧相等（−6/−18/−28/−31/−37/−45px 对同一组滚动量），即 1:1 上移，**不是**钉在栏上缩放或自上而下遮罩（逐行比对 8 行比率无梯度）；在位移之外另有**独立淡出曲线**（0→19.97dp 归零）。
  2. 紧凑标题在大标题**归零之后**才淡入（19.97→29.31dp），**两段不重叠**。
  3. 顶栏遮挡 = **纯色遮罩**（实心段下沿 63.6dp + 1.5 次幂渐隐裙边到 128.9dp，拟合 `alpha(y)=1−clamp((y−63.6)/65.3,0,1)^1.5`）；**实测无 backdrop 模糊**：均匀色块在遮罩下出现亮度斜坡（模糊不会）、卡片硬边 3px 内完成跳变（无拖尾）。→ 刻意不复用 `MiGlassPalette`，并在 doc 写明。
  4. 按压反馈：⌀44.1 圆盘、白 @9.4%，逐帧 0→25%→83%→100%（0.42s easeOut），松开 0.3s 消失。
- **几何实测**：圆钮 ⌀44.1 / 左 11.9 / 垂心 76.0（= 状态下沿 236px）；箭头墨盒 11.68×21.31（两臂 45°、横切 9px→笔宽 2.05、圆角端头；反解中心线得 L=9.63dp，与阈值实测 ±0.08dp 吻合），**墨心比圆钮中心左偏 1.3dp**（实测光学偏置）；大标题墨盒 155.3×29.6 / 墨左 29.6 / 墨心 y 132.9 / advance 31.83dp，紧凑标题墨盒 87.9×16.75 / 屏心 / 墨心 y 75.9 / advance 18.0dp；内容首行顶缘 183。
- **行盒 vs 墨心**：Flutter `Text` 按行盒布局，实测目标是墨心 → 加 0.126em（CJK 字面比例行距下的上偏量）修正，故 `largeTitleBoxCenterY=136.9` / `compactTitleBoxCenterY=78.2`（字体族变化需回校）。
- **组件**：`navigation/top_bar/`（MiTopBar + MiTopBarMetrics，含 12 点 + 8 点**折叠查找表**线性插值）+ token `theme/top_bar_tokens.dart`（MiTopBarPalette：暗色配方实测、浅色配方**推导**，遮罩基色取实测页底 #F3F3F3）+ `BackChevronIconPainter` 入 `icons/nav_icons.dart` + `MiTypography.topBarLargeTitle(31.83)/topBarCompactTitle(18.0)`；barrel +3 export。
- **API 决策**：**受控组件**（`scrollOffset` 由宿主注入，与 `MiPillTabBar.selectedIndex` 同风格），组件不自带滚动；坐标原点 = 屏幕顶端（几何已含状态栏让位，故不设 `statusBarHeight` 参数、demo 不叠 SafeArea）；遮罩/标题全 `IgnorePointer`，只有返回圆钮吃手势；负位移/NaN 构造期断言、+∞ 饱和为折叠完成态（`MiTopBarMetrics.collapsedOffset`）。
- **demo**：`mock_pages.dart` 页面壳改 `StatefulWidget`，`ScrollController` → `ValueNotifier` → `ValueListenableBuilder` 只重建顶栏一层；ListView 上内边距 = `MiTopBarMetrics.contentTopInset`。
- **测试**：新增 `test/top_bar_test.dart`（折叠曲线锚点/单调性/非有限位移、几何钉值、交互穿透与按压圆盘、const 构造）；预览测试新增 `doc/preview/top_bar_light|dark.png`（每格上=静止、下=滚动 105dp 让卡片穿进遮罩显形 —— 原 40dp 的方案看不出遮罩效果，已改）。
